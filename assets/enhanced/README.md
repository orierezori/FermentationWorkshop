# Enhanced site images

These are non-destructive, AI-assisted touch-ups of the original `workshop1`–`workshop13` photos and `logo_mutsasim.png` in the repository root. The originals remain available for comparison or rollback.

The edit brief for each photo was: preserve the real subject, object counts, composition, camera angle, people, and square framing; improve only exposure, white balance, noise, and natural detail; add or remove nothing; avoid stylization, text, and watermarks. Each photo was reviewed before use. The selected outputs were encoded as JPEG at quality 82 for the website.

The logo edit brief required the jar illustration, colors, layout, and the text “MUTSASIM”, “VEGETABLE FERMENTATION”, and “WORKSHOP” to remain exact. The PNG was reviewed for lettering accuracy. The 180, 192, and 512 pixel icons are size variants of that selected logo.
